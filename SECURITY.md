# Security Policy

## Reporting a Security Issue

If you find a security problem in Day Calculator, please report it privately instead of opening a public GitHub issue.

The **About** section in the app includes a Telegram link where you can reach out about security issues.

When reporting an issue, please include:

- What the problem is
- How to reproduce it
- Which version of Day Calculator you are using
- Screenshots or logs if they help explain the issue

Please don't publicly share details of a security issue before it has been reviewed.

## Supported Versions

Security fixes are generally provided for the latest released version.

Older versions may not receive security fixes, so updating to the latest release is recommended.

## About Day Calculator

Day Calculator is designed to work completely offline.

The app does not intentionally use:

- Internet or network services
- Online APIs
- Cloud services
- User accounts

If you find a security issue related to the app, reminders, notifications, widgets, local data, or dependencies, please report it privately.

Thank you for helping keep Day Calculator safe.
