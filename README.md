# Day Calculator

Day Calculator is a simple Android app for working with dates and keeping track of important days.

## Features

The app has six sections:

1. **Age Calculator** — Find your exact age.
2. **Date Difference** — Find the number of days between dates.
3. **Add / Subtract Date** — Calculate a new date by adding or subtracting time.
4. **Day Counter** — Count days from a date.
5. **Day of Week** — Find the weekday for any date.
6. **Date Reminder** — Remember important dates and keep track of them with countdowns.

### Date Reminder

Date Reminder supports yearly reminders for birthdays and anniversaries. It also includes home-screen widgets in 2×2 and 4×2 sizes.

### Other

- Light and dark mode
- Works offline
- No internet connection is required     for the main features.
